# Reference thumbnails

Put store screenshots of comparable games here (for example Townscaper and
Tiny Glade) as PNG, JPEG, or WebP files. `npm run capture-test` scales each one
to 200 px and places it on the contact sheet in `test-output/` in a shuffled
order next to the Little Tides screenshots.

The files are not part of the repository. They stay on the machine that runs
the test.
